# SSTap Next 0.3.6 — 双栈 DNS、测速容错与可读性完善

## 本轮目标

在保留 0.3.5 当前 IPv4-only 默认稳定行为的前提下，补齐 IPv6 环境可选能力、修复测速源 HTTP 403 的单点故障、改善系统接管按钮状态反馈、支持手动替换 sing-box 核心，并进行全 UI 字体可读性提升。

## 变更

### DNS / IPv6

- 默认仍为 `ipv4_only`，不改变现有安装的默认联网行为。
- 新增 `prefer_ipv4`（双栈、IPv4 优先）和 `prefer_ipv6`（双栈、IPv6 优先）。两者均允许 A/AAAA 解析。
- TUN 接口仍保留 IPv4/IPv6 地址及路由接管；不因 DNS 选择而关闭 IPv6 路由或让 IPv6 流量绕过 TUN。
- 只能在断开 TUN 后修改 DNS 地址族；修改后下一次 TUN 启动生效。
- 这两个双栈选项需要实际接入网络与代理节点出口都具备可用 IPv6。只有路由器 WAN 获得 IPv6 地址并不足以保证代理 IPv6 可用。

### 测速

- 默认测速文件改为 Hetzner FSN1 官方 1GB 测试文件，备用 ASH/NBG1 镜像，以及 OVHcloud、Tele2 跨服务商镜像，避免同一服务商整体拒绝时所有备用源同时失效。
- 主测速源遭遇 HTTP 403/404/408/429/5xx 或可重试网络/TLS错误时，会切换下一个来源，并在进度区域说明当前切换。
- 旧版默认 Cloudflare 测速 URL 会自动迁移到新的 Hetzner 默认地址；用户自定义测速地址保留。
- 测速数据量上限统一为 1 GB，避免超过固定文件大小；使用 HTTP Range 分段/流式下载，不将测试文件写入磁盘。
- 实际测速源记录在结果中，便于判断使用了哪个镜像。

### 主接管按钮与 UI

- 系统接管主按钮增加明确的启用渐变、悬停高亮、按下反馈与键盘焦点样式；运行中使用独立断开状态。
- 不满足启动条件时继续禁用按钮，但在按钮下方说明原因，包括未选择节点、本地代理尚未断开、核心未就绪或上次清理异常。
- 全局提升小字号：当前 CSS 字体声明最小值提升到 14px；常用正文、标签、辅助说明和列表文字统一增大，标题层级保留。保留标题字号层级，不重做原有布局。

### sing-box 内核管理

- 设置页显示当前实际核心版本和可执行文件路径，并提供“打开内核目录”。
- 不增加后台自动更新；用户可以从官方 GitHub Releases 手动下载 Windows amd64 正式版，备份后替换 EXE 与同包 DLL。
- 真实核心版本不再被配置检查脚本硬性限定为 1.14.4；构建时使用目录内实际核心执行 54 份配置检查，失败即停止打包。
- 默认下载脚本仍固定使用 1.14.4 与原 SHA-256 锁定值。手动核心不会被现有文件检测流程自动覆盖。
- 详细操作见 `docs/CORE-UPGRADE.md`。

## 测试范围与限制

本轮在开发容器实际执行：Node 自动化测试 65/65；704/704 个 package-lock 依赖引用通过；22 个 JS/CJS/MJS 文件通过 `node --check`；6 个 PowerShell 脚本全部为 UTF-8 BOM；97 条显式 CSS 字号声明的最小值为 14px。

当前容器不是 Windows，且没有 .NET 10 SDK、Windows sing-box 核心和 NSIS。因此本轮不会把 Agent 编译、54 份真实 sing-box 核心检查、前端 TypeScript/Vite 构建、安装包生成或 Wintun 实机行为标为已通过。请在 Windows 11 上按 `scripts\Build-Windows.ps1` 和 `docs\WINDOWS-ACCEPTANCE.md` 验收。
